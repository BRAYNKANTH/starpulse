Typefaces for the signature poster designs, from the Fontsource npm packages (Latin subset only).
All are licensed under the SIL Open Font License 1.1: https://openfontlicense.org

Young Serif, Hanken Grotesk, Bodoni Moda, Anton, Barlow Condensed, Cormorant Garamond.

They live in the repo, not on a font CDN, because the PNG download embeds them in the image.
